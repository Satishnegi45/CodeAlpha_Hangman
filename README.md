# Hangman Game

This is a simple text-based Hangman game made using Python.

## About the Project

In this game, the computer randomly selects a word from a list of 5 predefined words. The player has to guess the word one letter at a time.

The player gets a maximum of 6 wrong guesses.

## Features

- Random word selection
- 5 predefined words
- Guess the word one letter at a time
- Maximum 6 wrong guesses
- Checks repeated letters
- Checks invalid input
- Displays the guessed letters
- Shows win and game over messages

## Concepts Used

- Python lists
- Strings
- `random`
- `while` loop
- `for` loop
- `if-else`
- `break`
- `continue`
- User input

## How to Run

1. Make sure Python is installed.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

```bash
python hangman.py
```

5. Enter one letter at a time to guess the word.
